# Feature Walkthrough — Seedance 2.0

High-energy product showcase where a person actively demonstrates features while wearing or using the product.

## Core Principle: Show, Don't Tell

Every feature claim requires physical proof on camera. Don't say "hidden pocket" — show the person reaching into it.

## 7-Layer Structure

### Layer 1: Format Header
```
15s vertical phone video. Bright, even lighting. [Angle: eye level / slight above].
Fast-paced smartphone footage.
```

### Layer 2: Person + Product
Person and product are visually inseparable from frame one:
```
[Age]-year-old [gender], [clothing that is/includes the product from the first frame].
[Product name and key visual identifying feature].
```

### Layer 3: Setting
Simple residential background that doesn't compete:
```
[e.g., living room couch / kitchen counter / home entryway].
Clean but lived-in — not staged.
```

### Layer 4: Feature Beats
One feature per beat, dialogue + physical demonstration:
```
Hook (0–3s): "[Attention-grabbing opening line]" — [immediate product reveal gesture]
Beat 1 (3–7s): "[Feature 1 claim]" — [physical demo of feature 1]
Beat 2 (7–11s): "[Feature 2 claim]" — [physical demo of feature 2]
Kicker (11–15s): "[CTA or payoff line]" — [hold product to camera / final gesture]
```

### Layer 5: Graphic Overlays (Optional)
```
Text captions appear at beat transitions.
Size references, color swatches, or specs as needed.
```

### Layer 6: Tone & Pacing
```
Fast-paced, confident, energetic delivery.
Punchy and specific — no hedging language.
Emphasize material details and design choices.
```

### Layer 7: Technical Quality
```
Bright, even smartphone lighting. No grain. Sharp focus.
Phone microphone audio. Natural room ambience.
```

## Multi-Clip Strategy

For products with 3+ features, develop 2–3 separate clips:
- Clip 1: Hook + Features 1–2 + Kicker
- Clip 2: Hook variant + Features 3–4 + Kicker
- Each clip stands alone and works independently

## Dialogue Rules

- Punchy and specific — no hedging language
- Emphasize material details: fabric, weight, texture, dimensions
- Each clip: hook + 1–2 feature demos + kicker
