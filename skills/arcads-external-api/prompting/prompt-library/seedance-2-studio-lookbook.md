# Studio Lookbook — Seedance 2.0

Polished product showcase that feels like a short brand film. Fills the gap between UGC and commercial production.

## Core Characteristics

- **Visual-first storytelling:** Visuals lead, voice follows — narrator describes what viewers see
- **Multi-look versatility:** Same product in 2–3 different styling combinations
- **Behind-the-scenes authenticity:** Deliberately reveal studio equipment (lights, camera rig, monitor)

## 7-Layer Structure

### Layer 1: Format Header
```
15s vertical video. [Camera system: mirrorless / DSLR style].
[Lighting: softbox key light / ring light / natural + fill].
Polished but not over-produced.
```

### Layer 2: Person & Styling
```
[Age]-year-old [gender] model. 
Outfit 1: [description with product].
Outfit 2: [description with product].
[Optional Outfit 3].
```

### Layer 3: Studio Setting
```
[Backdrop color/texture: white seamless / warm grey / concrete].
Studio equipment visible: light stand, camera rig, monitor.
Behind-the-scenes transparency.
```

### Layer 4: Shot Sequence
```
Shot 1 (0–4s): Seated inspection — model examines product detail.
Shot 2 (4–8s): Full-body standing — product in context of outfit.
Shot 3 (8–11s): Close-up detail shot — [specific product feature].
Shot 4 (11–15s): BTS reveal — camera rig visible, model aware of filming.
```

### Layer 5: Voiceover Script
```
No lip-sync required. Narrator uses first person, does not address camera.
"[Line 1 describing what's visible]"
"[Line 2 highlighting product feature]"
"[Line 3 or CTA]"
```

### Layer 6: Tone & Pacing
```
Emotional arc: [e.g., discovery → appreciation → confidence].
Rhythm: each shot lingers 3–4 seconds. Unhurried.
```

### Layer 7: Technical Quality
```
[Lighting specs]. [Camera movement: none / slow pan / gentle zoom].
Clear audio — no room noise. Music underneath voiceover.
```

## Critical Constraints

- 15 seconds maximum
- 3–4 shots per clip, each lingering 3–4 seconds
- No lip-sync required for voiceover
- First person narration, not addressing camera
- At least one close-up detail + one BTS reveal
- Forbidden words: "cinematic," "professional," "stunning," "8k"
