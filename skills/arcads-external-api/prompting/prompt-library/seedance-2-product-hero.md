# Product Hero — Seedance 2.0

15-second product showcase videos. Product is the sole subject — no people.

## Best Suited For

Beverages, supplements, cosmetics, tech gadgets, and packaged goods with strong visual packaging.

## 6-Layer Structure

### Layer 1: Format Header
```
15s vertical video. High-contrast dramatic lighting. Deep color backdrop.
[9:16 aspect ratio].
```

### Layer 2: Product Description
```
[Product name and packaging description]. [Key visual feature: label, color, texture, shape].
Product is the brightest element in frame.
```

### Layer 3: Environment Setup
```
Deep [color: blue / black / teal / amber] backdrop. 
[Elemental environment: water surface / ice platform / rain / condensation droplets].
```

### Layer 4: Shot Sequence (3–4 escalating shots)
```
Shot 1 (0–4s): [Intimate texture/detail — extreme close-up of surface].
Shot 2 (4–8s): [Elemental interaction — water splash / ice shatter / rain droplets].
Shot 3 (8–12s): [Hero composition — full product, dramatic lighting].
Shot 4 (12–15s): [Final heroic angle — low angle looking up / slow orbital].
```

### Layer 5: Text Overlays
```
[Product name] appears at [timing].
[Key claim or tagline] appears at [timing].
[Optional: logo].
```

### Layer 6: Technical Specifications
```
Sharp focus on product throughout. Slow-motion for elemental effects.
Dramatic music plus foley sounds (no dialogue).
Deep, saturated backdrop with neutral product tones.
```

## Production Notes

- High contrast: product is brightest element
- Use macro detail shots for texture
- Water/ice interaction creates kinetic energy without needing people
- Color grade: deep saturated backdrop, neutral product tones
