# UGC Video Prompt Formula — Seedance 2.0

Framework for creating authentic user-generated content video prompts for any product category.

## The 9-Layer Structure

### Layer 1: Format Header
Technical specifications:
```
[Duration]s vertical phone video. Natural phone quality, not color graded.
[Lighting]: [e.g., bright natural window light / warm kitchen overhead].
[Angle]: [e.g., handheld slightly below eye level / front-facing selfie angle].
```

### Layer 2: Person
Realistic human with visible imperfections:
```
[Age]-year-old [gender], [hair], [visible skin texture: pores, slight unevenness, minor undereye shadows].
[Build/clothing that fits the context].
```

### Layer 3: Setting
Lived-in environment with specific context:
```
[Room] in [type of home]. [Specific details: cluttered counter, morning coffee, laundry nearby].
[Background detail that suggests real life, not staged].
```

### Layer 4: Product Introduction
How the product physically enters the frame:
```
[Person] reaches off-screen and picks up [product]. Holds it up so label faces camera.
[First physical interaction: reads label, turns it over, squeezes/opens it].
```

### Layer 5: Script Beats
Jump-cut sequences with dialogue and actions:
```
Beat 1 (0–4s): "[Opening line spoken naturally]" — [physical action simultaneously]
Beat 2 (4–8s): [Silent action beat: sipping, inspecting, applying]
Beat 3 (8–12s): "[Second dialogue line]" — [demonstrating result or feature]
Beat 4 (12–15s): "[CTA or wrap-up line]" — [product held to camera]
```

**Read every dialogue line aloud at natural pace before writing it. Silent beats are mandatory — do not cram all 15s with speech.**

### Layer 6: Tone Direction
```
Delivery: [e.g., casual and conversational / enthusiastic but not salesy / quiet confidence].
Energy: [e.g., just woke up / mid-routine / post-workout].
Emotional arc: [e.g., skeptical → surprised → convinced].
```

### Layer 7: Edit Style
```
[e.g., jump cuts between beats / single continuous take / two angle cuts].
Each take feels slightly imperfect — slight repositioning between cuts.
```

### Layer 8: Technical Flaws (Non-Negotiable)
```
Phone camera grain, slight motion blur on fast movements, soft focus on edges,
occasional autofocus adjustment, slight overexposure near window.
Phone microphone audio with room ambience and natural mouth sounds.
```

### Layer 9: Vibe Statement
One-sentence emotional anchor:
```
This feels like [e.g., a text message your friend sent you before a flight / an unpaid honest review].
```

## Duration Guidelines

- **10s video:** 1–2 spoken lines + one silent beat
- **15s video:** 3–4 beats with flexible spoken/silent balance

## Verification Checklist

- [ ] All 9 layers present
- [ ] Dialogue read aloud — fits duration at natural pace
- [ ] At least one silent beat included
- [ ] Technical flaw block present
- [ ] No polished aesthetics language ("studio," "professional," "cinematic")
- [ ] Word count 100–260
