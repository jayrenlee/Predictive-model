# Premium Product Reveal — Seedance 2.0

15-second dramatic product launch template. The product IS the star, floating in a void of black with dramatic lighting.

## Core Concept

No people, no environments, no lifestyle context. Pure dramatic restraint.

## 6-Layer Formula

### Layer 1: Pure Black Backdrop
```
Pure black background. No environmental context. No visible light sources.
Product floating in void.
```

### Layer 2: Product Hero Shot
```
[Product name] center frame. [Material description: metallic surfaces / glass edges / textured materials].
Strategic rim lighting catches [specific surface quality].
```

### Layer 3: Animated Text Reveals
```
Maximum 3 lines of text. [Line 1 content]. [Line 2 content]. [Line 3 content].
Text fades in sequentially, one per beat.
```

### Layer 4: Camera Movement
```
[Movement sequence: slow orbital / gradual zoom / tilt reveal].
Minimum 3–5 seconds per camera transition. Deliberate, slow pacing.
```

### Layer 5: Variant Comparisons (Optional)
```
[If showing variants: side-by-side reveal / sequential product swap].
[Color options / size variants].
```

### Layer 6: Final Branding Card
```
[Brand name] appears. [Tagline if applicable]. Fade to black.
```

## Technical Specs

- **Lighting:** Rim/edge lighting as primary illumination
- **Focus:** Ultra-sharp throughout
- **Motion:** Smooth and deliberate — never fast
- **Format:** 9:16 vertical for social
- **Audio:** Dramatic music (no dialogue, no foley)

## Tone

Deliberate and slow — the opposite of UGC content's spontaneous energy. Premium, theatrical, restrained.

## Use Cases

- New model/product line announcement
- Material quality showcase via close-ups
- Color/size variant comparison
